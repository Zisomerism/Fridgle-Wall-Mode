# Fridgle wall mode (Tampermonkey)

A userscript for [fridgle.net](https://fridgle.net) that adds a **wall mode** button at the top of the page to expand all word pool dropdowns.
It's best to collapse all of the dropdowns again when you are ready to make your sentence. If you attempt to move a word to the sentence section without toggling wall mode it will close all of the word dropdowns and might behave a little weird, but clicking on the word again should make it go back to normal.
